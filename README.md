## 🚀 Usage

On linux, you should be able to launch the executable like:

```bash
cd timer
./Timer
```

On windows, there's NO support. Sorry. It may change in the future.

## 🔨 Building

For linux users, i left a "compile.sh" file, which does all the job for you.
The only thing you'll need is the GCC (for g++) compiler.

For windows users, there's no support. But you can try building it with MinGW.
